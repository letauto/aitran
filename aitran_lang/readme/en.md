# aitran_lang

Language codes supported by widely used systems and software, `Code` enum, and native / English / Chinese names. No runtime dependency beyond the `strum` derive.

## Features

- `Code`: all 93 languages, `repr(u8)`, `as_str` / `AsRef<str>` / `Display` generated by strum
- `NAME` / `EN` / `ZH`: endonyms / English names / Chinese names
- `by_code`: parses `zh-CN`, `zh-TW`, `en-US`, `fil-PH`, etc. Case-insensitive, `-` and `_` are equivalent

## Usage

```rust
use aitran_lang::{by_code, Code, NAME};

assert_eq!(by_code("zh-CN"), Some(Code::Zh));
assert_eq!(by_code("zh-TW"), Some(Code::ZhTW));
assert_eq!(by_code("en-US"), Some(Code::En));
assert_eq!(Code::Zh.as_str(), "zh");
assert_eq!(Code::ZhTW.to_string(), "zh-TW");
assert_eq!(NAME[Code::Zh as usize], "简体中文");
```

## Parsing rules

1. Case-insensitive, `-` and `_` are equivalent
2. Match the primary subtag (`en-US` → `en`)
3. `zh` is split by region / script: `TW` / `HK` / `MO` / `Hant` → `ZhTW`, otherwise `Zh`
